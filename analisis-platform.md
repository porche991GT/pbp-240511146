# Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa Utama** | HTML, CSS, JavaScript, TypeScript | C++, C#, Java, Python | Kotlin, Swift, Dart, Java |
| **Arsitektur** | Client-Server (Browser & Server) | Standalone / Client-Server Lokal | Client-Server / Monolitik Ringan |
| **Cara Distribusi** | URL / Server Web (Tanpa Install) | Installer (.exe, .dmg, .deb) | App Store, Google Play Store (APK/AAB) |
| **Keunggulan** | Akses cepat, *cross-platform*, tidak perlu instalasi | Performa tinggi, akses hardware luas, bisa *offline* | Portabel, akses fitur HP (GPS, kamera, sensor) |
| **Keterbatasan** | Keterbatasan akses hardware, tergantung koneksi internet | Terikat OS tertentu, ukuran file instalasi besar | Batasan daya baterai, ukuran layar terbatas |
| **Contoh Aplikasi** | Canva, Google Docs | Visual Studio Code, Adobe Photoshop | WhatsApp, Instagram |
